# Voltr SDK Documentation

Generated API documentation for the Voltr SDKs.

## Contents

- **[`js/`](./js/)** — TypeScript SDK docs (generated by [TypeDoc](https://typedoc.org/))
- **[`rust/`](./rust/)** — Rust crate docs (generated by [`cargo doc`](https://doc.rust-lang.org/cargo/commands/cargo-doc.html))

## How it works

Documentation is automatically generated and pushed to this repo by CI in the [vault-program](https://github.com/voltrxyz/vault-program) repository. Each successful build on `main` regenerates the docs and commits them here.

### Viewing locally

Clone the repo and open the HTML files directly:

```bash
# TypeScript SDK docs
open js/index.html

# Rust crate docs
open rust/voltr_vault/index.html
```
