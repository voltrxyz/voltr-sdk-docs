Expand description

Computes the LP tokens that would be minted as management fees if the vault were settled at current_time_secs.

Returns 0 when nothing has accrued yet, when no fee is configured, or when the vault is empty. Mirrors calculateUnrealisedLpFees in the JS SDK using u128 math throughout to avoid the overflows that would otherwise occur for large vaults.
