Functions§

calculate_assets_for_withdraw
Returns the asset amount that lp_amount would redeem for, accounting for locked profit, accumulated/unrealised fees, dead-weight and the redemption fee. Mirrors calc_withdraw_asset_to_redeem on-chain.
calculate_lp_for_deposit
Returns the LP amount the user would actually receive for a deposit of asset_amount, after the program subtracts DEAD_WEIGHT on the first deposit.
calculate_lp_for_withdraw
Returns the LP amount that must be burned to redeem asset_amount from the vault. Mirrors calc_withdraw_lp_to_burn on-chain, including its ceil rounding — never quote fewer LP than the program would actually require.
current_asset_per_lp
Returns total_value / total_lp_supply, where total_lp_supply is the on-chain get_total_lp_supply_incl_fees: circulating LP + accumulated unharvested fees + the locked dead-weight.
lp_supply_breakdown
Computes LpSupplyBreakdown for the vault at current_time_secs.
