PDA derivation helpers that mirror the JS-only generated PDAs.

The codama Rust renderer does not yet emit find_*_pda helpers, so we provide the ones the SDK extension functions rely on.

Constants§

METAPLEX_METADATA_PROGRAM_ID
Metaplex Token Metadata program ID. Codama can’t derive PDAs that depend on an external program, so this stays hand-written.
