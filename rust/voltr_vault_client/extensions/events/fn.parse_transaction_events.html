pub fn parse_transaction_events<S: AsRef<str>>(
    log_messages: &[S],
) -> Vec<ParsedVoltrEvent>
Expand description

Walk a transaction’s log messages, decode every Voltr event emitted via Anchor’s emit!, and return them in emission order. Lines whose discriminator doesn’t belong to a Voltr event are skipped, so logs from other programs in the same tx are safe to pass through.
