Module fetch 

Source
Expand description

Convenience batch fetchers that mirror the JS SDK’s fetchAll* helpers. Gated behind the fetch feature.

Each helper builds a getProgramAccounts call against the Voltr vault program with a memcmp filter on the receipt’s vault field (offset 8, immediately after the discriminator).
